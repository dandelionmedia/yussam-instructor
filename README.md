# 친절한유성쌤 김유성 강사 소개

AI콘텐츠마케팅연구소 유쌤클래스 김유성 강사의 소개 사이트입니다.

공식 소개: https://www.yussamclass.com/32

## GitHub Pages 게시

1. 공개 저장소 `yussam-instructor`를 만듭니다.
2. 이 폴더의 파일과 하위 폴더를 모두 저장소 최상위에 업로드합니다. ZIP 파일 자체를 업로드하지 마세요.
3. Settings → Pages → Build and deployment에서 `Deploy from a branch`를 선택합니다.
4. Branch는 `main`, 폴더는 `/ (root)`로 선택하고 Save를 누릅니다.
5. 게시 완료 후 https://dandelionmedia.github.io/yussam-instructor/ 에 접속합니다.

## 포함 기능

프로필·경력·학력·자격, 강의 분야 9개, 저서 5권, 교육 이력, 갤러리, 보도자료 검색, 토요라이브스터디 안내, 글자 크기 조절, 질문 도우미, 공식 문의 연결.

AI 소식은 수집 당시 자료이며 자동 갱신은 연결되어 있지 않습니다.

## 경로

메인 페이지: `index.html`
사진과 자료: 같은 폴더의 이미지·JSON 및 `books`, `gallery`
하위 페이지: `privacy`, `terms`, `email-policy`, `events/yussam-live-study`

기존 사이트의 화면과 기능은 유지하고 GitHub Pages의 저장소 하위 주소에 맞게 내부 링크를 수정했습니다.
